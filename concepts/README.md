# Seven Directions — visual proof of the process

[Open the visual concept explorer](./index.html) or, once GitHub Pages is enabled, visit:
https://azrielchoerulhakim.github.io/lazarus-design-os/concepts/

**IMPORTANT:** These seven runnable illustrations are speculative **concept artboards**, not final websites or built-out client projects. They use one *fictional* brief so you can judge differences in information architecture, imagery, typographic hierarchy, and interaction approach under equal conditions.

## Hypothetical brief
ATELIER SERA — fictional small independent architecture studio, 4 fictitious projects named Rumah Sore / Paviliun Utara / Ruang Pantai / Studio Tanah. All project details, visuals, coordinates and claims are placeholder experiments, not asserted facts about a real business.

## Seven independent design hypotheses

| # | Direction | Primary information architecture | Main relationship |
|---|---|---|---|
| 01 | The Monograph | Reading a designed volume, chapter by chapter | work as editorial publication |
| 02 | Cartography | Select a place, read its site dossier | work as contextual geography |
| 03 | Film Sequence | Move through cinematic story chapters | work as a visual narrative |
| 04 | Blueprint | Navigate projects as technical documents | work as evidence and decisions |
| 05 | Public Index | Scan a civic typographic ledger | work as a public record |
| 06 | Object Gallery | Focus on one model and inspect it | work as a spatial artifact |
| 07 | Material Journal | Trace material, sketch and daylight studies | work as an experimental process |

## What this demonstration proves and does not
It visibly demonstrates **seven distinct compositions and interaction grammars** for the same hypothetical client. It does not establish which one is “best,” meet production performance targets, replace real case studies, or validate any design in a user test. Individual artboards contain illustrative SVG/CSS and stand-in copy.

## Using the concept system with a real client
1. Read verified CV, photography, projects and user needs first.
2. Generate seven proposals with distinct structures **from the client evidence**, not automatically these same seven artboards.
3. Compare tradeoffs and choose **one** to develop.
4. Build the real website in the client repo; add real assets and functional controls.
5. Run the anti-generic and craft audits; document what was and was not tested.

## How to use the concept explorer
Open `index.html` from a web server. Click one of seven direction tabs or use arrow buttons. The arrow keys also change the selected direction. Interactive hotspots in Map, Film Sequence, Blueprint, Public Index and Object Gallery switch their internal state.

This sandbox includes original concept code only and does not distribute any of the seven previous historical source examples.
