## Distinguish three access levels

1. `notes-only`: The current agent can read only the public Design OS study notes. This is the default for new client projects.
2. `authorized-source-inspected`: An authorized source file is directly accessible and inspected in the *current* project. Name the accessible source in the record. This does **not** by itself confer permission to redistribute source or assets.
3. Rights to *reuse/publish*: A separate permission/licensing determination, outside the scope of the presence or checksum of a file. Check individual asset rights before client publication.

**Inspection limit:** The source files were inspected for identifiable routines, lifecycle behaviors and interaction principles. This is not a full browser security, copyright chain-of-title, benchmark, dependency or production deployment audit of the seven original prototypes.
