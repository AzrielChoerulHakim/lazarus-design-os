# Source code, attribution and public-repository policy

This GitHub repository was found **PUBLIC** when initialized. User-supplied historical reference studies may contain third-party logos, imagery, fonts, videos or source whose redistribution rights have not been established.

**Therefore this repository intentionally does NOT contain full source files or bundled media from the seven historical examples.** Its seven study analyses are text summaries of techniques. Technical notes are conceptual; anyone requiring line-by-line verification must obtain the original files separately and check usage rights.

External Apple and design-agent skills are linked, not mirrored. They are not official Apple materials except Apple's own HIG; their descriptions and code examples may contain author interpretation or inaccuracies. Follow applicable licenses and verify with primary technical sources.

Never:
- Publish or resell third-party assets without rights.
- Clone Apple.com appearance, brand marks, product imagery or copy.
- Redistribute restricted Apple font binaries (San Francisco, New York) as generic web fonts.
- Treat “user uploaded a file” as conclusive evidence of copyright ownership.
- Attribute sample businesses or hypothetical demos to real clients.

The original static HTML/CSS/JS and author-written design framework in this repo are new project implementation material; no general-purpose external license is asserted until the repo owner chooses one.
