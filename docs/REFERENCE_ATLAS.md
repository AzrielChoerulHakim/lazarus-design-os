## Selection protocol
1. Define the client's actual communication problem **without naming a reference**.
2. Identify one useful mechanism (e.g., synchronized time progression).
3. State why the mechanism helps this client's real content.
4. Write what you will *not* transplant: source palette, typography, hero anatomy, copy, composition, imagery, brand, and distinctive artwork.
5. Verify original implementation if access and rights allow; otherwise treat this as a design-method note only.
6. Implement an original solution and audit mobile, keyboard, zoom and reduced motion.

## Source diversity warning
Seven visually different demos are not seven conceptually different site structures. Several references share huge display typography, mini mono labels, sticky chapters or dramatic transitions. Do not inherit that cluster as a Lazarus house style.
