# 04 / Cullet
**Study classification:** systems · materiality · process-state visualization.

**Historical source:** `cullet-standalone.html` (not republished); plain HTML/CSS/JS, Canvas 2D. Historical fonts: Unbounded and Manrope. It is a conceptual hot-glass making story; illustrative temperatures must not become factual client claims.

## What the source demonstrates
A progress variable derived from active scroll-stage geometry feeds `temperatureAt(progress)`, `phaseAt(progress)`, and `updateScroll()`. The graph, selected stage and supporting readout remain synchronized. Canvas routines such as `drawCurve()`, `drawGlow()`, and `drawGather()` evoke material changes; their source imagery is specific to molten glass.

A separate `fitWordmark()` pass checks actually rendered text width rather than trusting CSS `clamp()` alone. Visibility gates limit drawing work, and reduced motion is recognized.

## Transferable mechanism
Use a *single documented process state* to coordinate the visual diagram and written interpretation. Use measured typography when the composition depends on an unusually wide piece of text. The material treatment must reflect real practice or material qualities, not generic glow.

## Avoid
Ember colors, Unbounded display typography, identical pinned story, imaginary temperatures and heat contours applied to an unrelated client. The fact that code generates an effect does not make the effect relevant.

## Example transformation
A ceramicist with firing logs could visualize true kiln data and artifacts; an industrial engineer with process logs could make a factual interactive sequence. If data are missing, present a qualitative documented process rather than invented numbers.

## QA
Accurate data labels, screen reader summaries, progress synchronization in reverse, small-height viewports, reduced-motion static visualization, low-power Canvas rendering and type clipping.
