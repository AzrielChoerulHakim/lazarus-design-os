# LAZARUS DESIGN OS / NOIR LAB

Three **independent** original art-direction studies, not a production client template:
- **Red Noir / Crimson Interruption:** poster typography, hard red shaft, asymmetrical tension.
- **Blue Noir / After-Hours Transmission:** atmospheric blue depth, offset serif, diffuse illumination.
- **Black Noir / Negative Frame:** high-contrast monochrome, negative space, Venetian-blind shadows.

## Provenance and adaptation

Original implementation in `index.html`, `styles.css`, and `app.js` authored for Lazarus Design OS. The reference projects were **studied for mechanisms only**, not copied, mirrored, or bundled. No third-party source code or visual assets were redistributed.

## What was adapted

- CSS-generated film grain, directional light, shadow masks and staged composition.
- Distinct typography and page anatomy for each of the three directions.
- URL hash deep-linking, native buttons, accessible focus styles, responsive layouts, reduced-motion support.
- No borrowed hero artwork, trademark, original component implementation or reference copy.

## What was rejected

No automatic glass cards, glowing CTA pills, animated starfields, SaaS pricing structures, forced scroll hijacking, or generic hero-card-CTA anatomy.

## Fonts and assets

Uses Google Fonts CSS requests for Barlow Condensed, DM Mono, DM Sans, and Playfair Display with local fallbacks. Their font licenses must be verified before offline bundling or client deployment. SVG noise is generated by original CSS, no external imagery.

## Run

Open `noir/index.html` or serve the repo with `python3 -m http.server 8000` and visit `/noir/`. No build step. Do not claim browser QA, WCAG certification, or client readiness from this conceptual study. For a real client follow `AGENTS.md`, typography/voice/mobile gates and verified source content.
