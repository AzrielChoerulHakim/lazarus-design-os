# 01 / Sculptural Impasto — Visual Mapping System

**Status:** selected art direction, experimental mapping implementation. **Integration type:** optional additive module, NOT a replacement workflow.

## Why this module exists

Lazarus Design OS already owns the evidence flow, seven client-specific concepts, tone of voice, typography, anti-generic critique and mobile release gates. This module addresses one missing translation: **how the sculptural impasto oil-paint visual language becomes a client-specific, useful page composition**.

Source decision: the creative director selected **Sculptural Impasto** to replace 3D/photorealistic Surrealist Digital Editorial explorations. This is a decision about **visual medium**, not about how a client writes or what their actual work is.

### Reading order (optional, not mandatory)

1. [Visual DNA](VISUAL_DNA.md): recognizable attributes, material, pigment, contradiction, rejection tests.
2. [Composition Mapping](COMPOSITION_MAPPING.md): painting focal zones → information hierarchy → layout alternatives.
3. [Lighting & Depth Map](LIGHTING_DEPTH_MAP.md): light inside the depicted world versus light on raised paint.

8. [Three layout studies](../../visual-lab/sculptural-impasto/): independent working comparative layouts, **not three client sites**.

### Exact relationship to Design OS

**Existing systems remain authoritative:** AGENTS.md, DESIGN.md, docs/WORKFLOW.md, the five-family Tone of Voice System, Typography Direction, Originality Protocol, Mobile Visual Integrity and executable design-contract gates. This module has **no hooks in the existing validators**, changes no schema, alters no voice values and does not claim that a visual direction is suitable for every profession.

Inputs: selected Sculptural Impasto direction + client-verified facts + actual media + intended reader + the chosen client-specific information architecture.

Output: a justified image brief, focal and negative-space map, per-section composition choices, mobile artwork plan and visual-QA findings.

### Raster-only rule

- One scene = **one entire original raster painting**; never assemble light, stone, sky, cloth and sculpture as stacked elements on the page.
- No artistic SVG, CSS paint-over, multi-image hero collage, procedural fake impasto, 3D/parallax tricks or fake depth.
- **Legitimate HTML text, navigation and controls remain independent from the painting.** They are not baked into the raster.
- Crop only after mapping focal integrity. If mobile requires new framing, create an independently composed **complete mobile painting**, not layered cutouts.
- No permission to fabricate achievements or to disguise illustrative studies as actual client projects.

### Distinguish source and hypothesis

The art direction choice is approved by the creative director in the conversation. The images in this lab were generated as **original conceptual studies** and are not reproductions of specific Salvador Dalí paintings. All image compositions, suggested role mappings, pigment measurements and thresholds below are **design hypotheses** pending real-client evaluation. The documentation does not claim instrument-measured physical oil thickness or actual 3D normals.

### Promotion rule

This module may be reused as **research guidance** immediately. It becomes a production artwork benchmark only after original-resolution artwork is stored in the repository, the three alternatives and full-page layouts are reviewed, independent mobile QA passes, and a real client confirms suitability. **Do not merge or deploy a low-resolution transferred preview as final art.**
