# Section Grammar — the painting is not the navigation

The existing Design OS decides what the **visitor** needs to read and do. This file decides how an approved Sculptural Impasto painting can occupy space alongside that information.

## Available section patterns (not a forced sequence)

| Information task | Adaptable visual pattern | Should the painting be used? | Risk |
| --- | --- | --- | --- |
| Immediate identity | Tightly edited statement with an intact painting beside or following it | Only if client identity benefits from image-led opening | Hiding name, role or proof |
| Featured work | Evidence-first entry with description, date (if verified), role and links | A separate artwork only when genuinely relevant or clearly labeled illustrative | Mistaking metaphor for client work |
| Detailed chronology | Clear text-first index with accessible sections | Often **no** painting | Visual distraction or invented experience |
| About / point of view | A slower essay spread with an optional standalone image | Yes if it deepens client's proven practice | Invented first-person motivations |
| Contact | Plain, obvious action with enough contrast | Usually unnecessary | CTA lost against textured scene |

## Three mapped full-page studies

All three use the same fictional Atelier Sera text to test *layout*, not client suitability:

- **01 Gallery:** a two-column opening + art plate; project entries below without artwork stacks; plain contact band.
- **02 Folio:** narrow index and large painting plate; project notes organized as archival entries; clear close.
- **03 Passage:** a thesis page, then one uninterrupted painting; section-by-section factual annotations; contact end.

They share **content**, not layout. Site components and reading order differ; do not merely swap images in the same hero.

## Core prohibitions

- Never place separate clouds, moons, statues, cloth or relief shadows on top of a background image.
- Never use artistic SVG, CSS shapes, multibackground, canvas effects, clipping masks or artificial parallax to rebuild a scene.
- Real text and controls stay live accessible DOM. Do not rasterize CV details into the painting.
- Do not repeat the same painting in every section as wallpaper.
- Use an *art-free* section where information density needs it.

## Adaptation by client profile

A legal professional may need sober index-first structure and very little impasto imagery. An artist with documented work may justify a dramatic image-led exhibition. A developer with dense projects may choose an evidence-first archive; the visual direction does not override usability. In some briefs, Sculptural Impasto must be **rejected**, despite being an approved Lazarus direction.

The existing Tone of Voice and typography specifications remain completely unchanged.
